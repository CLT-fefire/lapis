# 태그 계층 설계

슬래시로 계층을 만든다. 앞자리를 몇 개로 좁게 유지하면 패널이 트리로 렌더한다.

앞자리 후보 — 기술, 문제 유형, 주제, 구조 결정. 속성이 이미 담는 값은
태그에 넣지 않는다. 두 곳에 같은 뜻이 있으면 갈라진다.
