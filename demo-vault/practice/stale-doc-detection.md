# 낡은 문서 찾기

문서가 낡았는지 자동으로 알 방법이 마땅치 않다. 수정 시각만으로는
여전히 맞는 문서와 방치된 문서를 구분하지 못한다.

후보 — 가리키는 문서가 대체된 경우, 언급한 파일이 사라진 경우.
