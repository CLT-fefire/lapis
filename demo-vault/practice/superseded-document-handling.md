# 대체된 문서 다루기

틀린 문서를 지우면 왜 틀렸는지가 사라진다. 남겨 두고 대체 문서를 가리킨다.

관계 종류를 보존하는 게 중요하다 — 그냥 관련된 문서와 이 문서를 고친 문서는
다르다. [[related-vs-amends]] 참조.
